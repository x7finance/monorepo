# How to borrow Liquidity

Trading on Xchange is very easy compared to most exchanges. You aren't going to be overwhelmed by charts or jargon, and trading routes and calculations are all handled for you by the Xchange Smart Router.

## Getting set up to trade

Before you can trade, you will need a wallet that is compatible. You can learn how to get one . You will also need to have some BEP-20 or ERC-20 tokens to trade with. You can learn how to get some .

## Trading on the Xchange exchange

1 - Visit the Liquidity tab [here](https://www.x7finance.org/liquidity)

​![ Page](/static/liquidity_page.png)

2 - Click on the `Initial Liquidity Loan` button

​![ Page](/static/liquidity_loan_blank.png)

​3 - Select the currency which you would like to create a liquidity pair with Eth (or native currency)

​![ Page](/static/liquidity_loan_token_select.png)

4 - Select the amount of Eth you would like to borrow.

​![ Page](/static/loan_eth_select.png)

5 - Select the loan duration.

​![ Page](/static/loan_length_select.png)

6 - Select the loan term for your project.

![page](/static/loan_term_highlighted.png)
