A private RPC endpoint is a unique URL designated exclusively for the owner's use to transmit transactions directly to the public mempool. This grants individuals a direct link to a node provider, offering a personalized connection.

The significance of private RPC endpoints lies in their ability to allow users to broadcast transactions via a dedicated endpoint, distinct from their wallet's default public endpoint, which is concurrently accessed by other users of the same wallet.

## Why choose a private RPC endpoint?

Opting for a private RPC endpoint yields various advantages, such as enhanced transaction speed, precise data, increased service reliability, and reduced competition when submitting transactions during peak periods.

To connect to your custom RPC, all you need to do is provide the Xchange UI with your private API key.
